# Archive Card: заметки по проекту

Шот для портфолио в жанре design engineering: интерактивная карточка общего диска с папками и анимированной архивацией. Два варианта одной карточки на чистом HTML, CSS и JS, без сборки и зависимостей.

## Структура

```
index.html                         стартовая страница со ссылками на оба варианта
variant-1-glass-folder/index.html  вариант 1: в hero одна большая стеклянная папка
variant-2-glass-box/index.html     вариант 2: в hero стеклянная коробка с папками
previews/                          скриншоты обоих вариантов, светлая и тёмная тема
scripts/screenshot.js              скрипт, который пересобирает превью (Playwright)
```

## Как запустить

Достаточно открыть `index.html` или любой `variant-*/index.html` в браузере. Сервер не нужен.

Для удобства можно поднять локальный сервер:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

Пересобрать превью (нужен Node.js и Playwright с Chromium):

```bash
node scripts/screenshot.js
```

Шрифт Geist грузится с Google Fonts. Без интернета подставится системный шрифт, вёрстка не ломается.

## Что сделано

Общее для обоих вариантов:

- Карточка во вложенной рамке: тёмный hero с авророй и шумом, под ним белая панель.
- В hero: название диска, кнопка «Show less», которая сворачивает панель, крупное число занятого места, плашки «of 100 GB» и «−10,10 GB ↘», тонкий бар по папкам.
- В панели переключатель Folders / Access с пружинящим ползунком.
- Folders: пять строк (Marketing, Brand Assets, Product Shots, Media Kit, Archive). В каждой мини-иконка, число файлов, теги, размер и цветная плашка с долей. Внизу широкая кнопка «Archive 23 idle files».
- Наведение на строку или сегмент бара выводит папку в hero: аврора перекрашивается в её цвет, заголовок меняется, числа прокручиваются. Клик закрепляет выбор, Esc или клик мимо снимает.
- Архивация: кнопка заполняется как прогресс-бар, листы бумаги с цветной меткой по дуге летят из Marketing, Brand Assets и Product Shots. Все цифры прокручиваются: 56,87 → 46,77 GB. Потом кнопка показывает «Archived 23 files · Undo», и Undo проигрывает всё обратно.
- Access: пять человек, клик по плашке роли переключает её по кругу (Can view → Can comment → Can edit). Кнопка «Invite teammate» добавляет ещё до трёх человек с плашкой «Invited».
- Светлая и тёмная тема (hero тёмный в обеих). При `prefers-reduced-motion` анимации отключаются.

Вариант 1, стеклянная папка:

- Большая папка в hero плавно перекрашивается в цвет наведённой папки: градиенты SVG завязаны на CSS-переменные. Листы в ней поднимаются по объёму папки.
- При архивации листы летят из строк в строку Archive (фиолетовая папка), она подпрыгивает при каждом попадании.

Вариант 2, стеклянная коробка (по первому референсу):

- Коробка в изометрии: передняя стенка из белого матового стекла, через неё размыто видны папки внутри. На стенке вдавленная ручка по центру сверху и тиснёный знак-волна. Боковая стенка из бирюзового стекла.
- Высота, на которую каждая папка торчит из коробки, равна её объёму × 2,8 px. Наведение поднимает папку ещё на 16 px, и из неё выезжает лист.
- Архивация: листы летят из строк вверх к коробке, превращаются в пачку, перевязанную лентой, пачка падает в коробку, коробка пружинит, папки проседают. Undo: пачка выпрыгивает и разлетается листами по строкам.
- У строки Archive иконка — маленькая копия той же коробки.

## Режим показа (запись экрана)

В обоих вариантах: `F` — полный экран (Fullscreen API, чёрный фон, курсор прячется через 1,5 с), `Space`/`Enter` — архивировать (повторно — Undo), `R` — сброс в исходное состояние (останавливает анимацию на лету), `−`/`+` — масштаб шагом 5 % (40–160 %), `0` — 100 %. Масштаб хранится в localStorage (`archive-card:zoom`). Клавиши ловятся по `e.code`, нажатия с Cmd/Ctrl/Alt игнорируются.

Карточка подгоняется под высоту окна через CSS `zoom` на `.shell`. Поэтому координаты летящих листов делятся на текущий zoom (`flySheet` в варианте 1, `local()` в варианте 2). Canvas нет, всё SVG/CSS, так что при масштабе ничего не мылится.

## Решения и почему

- **Один HTML-файл на вариант, без фреймворков.** Шот должен открываться где угодно и легко переноситься, включая публикацию как артефакт claude.ai. Библиотеки здесь ничего не дают.
- **Иллюстрации в SVG, а не картинками.** Цвета, высоты папок и анимации управляются из кода. Папки и коробка собираются функциями `folderSVG()` и `boxSVG()`, поэтому большая иллюстрация и мини-иконки в строках — один и тот же компонент.
- **Эффект матового стекла сделан двойной отрисовкой.** Листы или папки рисуются дважды: чётко над створкой или стенкой и размыто (`feGaussianBlur`) под ней, обрезано по её форме. `backdrop-filter` не использован: в SVG он не работает и по-разному ведёт себя в браузерах.
- **Высота папки кодирует данные.** Иллюстрация не просто украшение: по ней видно, какая папка самая тяжёлая.
- **Плавный цвет авроры через `@property`.** `--a1` и `--a2` зарегистрированы как `<color>`, поэтому градиент переходит плавно, а не скачком.
- **Данные выдуманы, но сходятся.** Сумма до архивации 56,87 GB, после 46,77 GB. Перемещается 23 файла (13,46 GB), они упаковываются в 3,36 GB, итого освобождается 10,10 GB. Число файлов не меняется (1 284). Все числа лежат в объекте `DATA` в начале скрипта.
- **Формат чисел европейский:** запятая в дробях, узкий пробел в тысячах (как в референсе «56,87 GB»).
- **Интерфейс на английском,** как в референсах, потому что шоты обычно показывают международной аудитории.
- **Названия папок взяты из референса** с папками: Media Kit, Brand Assets, Marketing.

## Как это развивалось

1. Первая версия: плоская иллюстрация с толстым чёрным контуром (коробка как в референсе «Archived files»), засечки Newsreader, карточка в духе Apple Storage. Её нет в репозитории, она осталась только в истории артефакта claude.ai.
2. Пользователь попросил иллюстрации как у стеклянных папок, а интерфейс современнее, по образцу финтех-карточки («Overview», тёмный градиентный hero, переключатель, список с плашками, широкая кнопка). Получился вариант 1.
3. Пользователь попросил ещё раз коробку из первого референса, но в стиле стеклянных папок. Получился вариант 2. Затем ручку на коробке перенесли в центр и наверх.

Референсы (чужие шоты с Dribbble и подобных сайтов) в репозиторий не положены, потому что это чужие работы:

- «Archived files»: плоская коробка с цветными папками, чёрный контур, бирюзовая боковая стенка.
- Apple Storage: стеклянная папка, бар по категориям, «Who has access» с аватарами.
- Стеклянные папки Media Kit, Brand Assets, Marketing Assets: синяя, серая, жёлтая, красная, глянцевые, с тиснёным знаком.
- Финтех-карточка Overview: тёмный hero с фиолетовой авророй, сумма, переключатель Top/Worst performance, список с зелёными плашками, кнопка Swap money.

## Что не доделано

- Нет перевода на русский: весь текст интерфейса английский.
- Нет README для GitHub и не настроен GitHub Pages (стартовая `index.html` для него готова).
- «Show less» сворачивает панель, но состояние нигде не сохраняется. То же с приглашениями и ролями в Access: после перезагрузки всё возвращается.
- На сенсорных экранах наведения нет: папку выбирают нажатием (это то же закрепление, что по клику мышью), отдельного превью для тача не сделано.
- Нет автотестов. Проверка делалась глазами по скриншотам (`scripts/screenshot.js`). Анимации полёта листов на скриншоте до конца не проверить, их стоит смотреть в браузере.
- Не проверено в Safari и Firefox: CSS `@property` и `color-mix()` нужны свежие версии (Safari 16.4+, Firefox 128+). В старых браузерах аврора переключается без плавного перехода.
- Эти данные — пример. Подключения к реальному хранилищу нет.
